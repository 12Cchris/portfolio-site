1. GitHub 연결 정보

토큰은 이 브라우저의 로컬 저장소(localStorage)에만 저장되고, GitHub API로만 직접 전송됩니다 — 어디에도 업로드되지 않습니다. 그래도 다른 사람의 기기나 공용 컴퓨터에는 절대 입력하지 마세요.
토큰은 GitHub → Settings → Developer settings → Fine-grained personal access tokens에서 이 저장소에 대해 Contents: Read and write 권한만 준 것을 새로 만들어 쓰는 걸 추천합니다.
아이콘 편집은 https://lucide.dev/icons/ 에서 진행하세요.

위 정보는 입력하는 즉시 자동으로 암호화되어 저장됩니다 (버튼은 안 눌러도 됩니다).

2. 프로젝트 편집

프로젝트가 한 줄씩 보입니다. 제목·상태·버전·플랫폼·최근 업데이트는 바로 고치고, 설명·링크·아이콘·기술 스택·특징은 [상세 ▾]를 눌러 펼쳐서 고치세요. 다 고쳤으면 맨 아래 저장 버튼을 누르면 됩니다.
기술 스택 규칙: 쉼표(,)로 구분해 적으면, 칸을 벗어날 때 자동으로 정리됩니다 — 공백 정리 · 대소문자만 다른 중복 제거 · 알려진 기술(HTML, GitHub Pages 등)은 공식 표기로 교정.
